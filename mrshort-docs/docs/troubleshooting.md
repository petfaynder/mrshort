# Troubleshooting

Common issues and how to solve them.

## Login Issues

### I can't log in

**Possible causes:**
1. Wrong email or password
2. Account not verified
3. Account suspended

**Solutions:**
1. Double-check your email and password
2. Check spam folder for verification email
3. Reset your password via "Forgot Password"
4. Contact support if issue persists

### I forgot my password

1. Click **Forgot Password** on login page
2. Enter your email address
3. Check your inbox (and spam folder)
4. Click the reset link
5. Create a new password

### 2FA code not working

- Make sure your phone's time is synced
- Wait for a new code (they refresh every 30 seconds)
- Use a backup code if available
- Contact support if you've lost access

## Link Issues

### My link isn't working

**Check:**
1. Is the original URL valid?
2. Is the link expired?
3. Is the link paused or hidden?

**Solution:**
Go to **Links**, find the link, and verify its status.

### Clicks aren't counting

**Possible reasons:**
- You clicked your own link
- Same IP clicked multiple times (24h cooldown)
- Bot or proxy traffic detected
- Link is hidden or paused

### Link shows error page

The destination URL might be:
- Down or deleted
- Blocking traffic
- Behind a firewall

Update the destination URL in link settings.

## Payment Issues

### Withdrawal stuck on "Pending"

Withdrawals are processed within:
- Crypto: 24 hours
- PayPal: 1-3 business days
- Bank: 3-5 business days

If it's taking longer, contact support.

### Withdrawal rejected

Common reasons:
- Invalid payment details
- Account verification needed
- Suspicious activity flagged

Check your email for rejection reason and fix the issue.

### Payment not received

1. Check withdrawal status in **Withdrawals**
2. Verify payment details are correct
3. Check your payment account (PayPal, wallet, etc.)
4. For crypto, verify transaction on blockchain

## Dashboard Issues

### Stats not updating

Stats update in real-time, but sometimes there's a delay:
- Wait a few minutes
- Refresh the page
- Clear browser cache

### Charts not loading

1. Refresh the page
2. Try a different browser
3. Disable browser extensions
4. Clear cache and cookies

### Page loading slow

- Check your internet connection
- Clear browser cache
- Try incognito/private mode
- Disable unnecessary extensions

---

## API Issues

### API returns 401 Unauthorized

- Check if your API token is valid
- Ensure token hasn't expired
- Verify you're using the correct token

### API rate limit exceeded

You've hit the rate limit:
- Wait 1 minute before retrying
- Upgrade VIP for higher limits
- Optimize your requests

### API not responding

- Check MRShort status page
- Verify your internet connection
- Try again in a few minutes

---

## Account Issues

### Account suspended

If your account is suspended:
1. Check email for suspension reason
2. Contact support with appeal
3. Wait for review (usually 24-48 hours)

### Can't change email

Email changes require:
1. Verification of current email
2. Verification of new email
3. Recent password confirmation

### Profile picture not updating

Profile pictures are auto-generated from your name. There's no manual upload option currently.
