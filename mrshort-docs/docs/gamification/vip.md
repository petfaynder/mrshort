# VIP Levels

Level up your account to unlock better rates and exclusive features!

## How VIP Works

Your VIP level is determined by your **XP (Experience Points)**. Earn XP by:
- Earning money through clicks
- Completing achievements
- Daily activities
- Referrals

## VIP Tiers

| Level | XP Required | Benefits |
|-------|-------------|----------|
| **Bronze** | 0 | Standard CPM rates |
| **Silver** | 1,000 XP | +5% CPM bonus |
| **Gold** | 5,000 XP | +10% CPM bonus, Priority support |
| **Platinum** | 20,000 XP | +15% CPM bonus, Early access to features |
| **Diamond** | 50,000 XP | +20% CPM bonus, Dedicated support |

## VIP Benefits

### Bronze (Starting Level)
- Access to all basic features
- Standard CPM rates
- Standard support

### Silver
- 5% bonus on all CPM earnings
- Increased API rate limits
- Silver badge on profile

### Gold
- 10% bonus on all CPM earnings
- Priority customer support
- Gold badge on profile
- Early access to beta features

### Platinum
- 15% bonus on all CPM earnings
- Extended analytics history
- Platinum badge on profile
- Exclusive Platinum-only promotions

### Diamond
- 20% bonus on all CPM earnings
- Dedicated account manager
- Diamond badge on profile
- Custom link domains (coming soon)
- Highest API rate limits

## Checking Your VIP Status

1. Go to **Gamification → VIP Status**
2. View your current level and XP
3. See progress to next level
4. Review your VIP benefits

## Tips to Level Up Fast

1. **Stay active daily** - Daily login bonuses add up
2. **Complete achievements** - Big XP rewards
3. **Refer friends** - Each referral gives XP
4. **Participate in competitions** - Weekly bonuses
5. **Spin daily** - Chance to win XP

## FAQ

### Can I lose VIP status?
No, once you reach a level, you keep it forever.

### Do VIP bonuses stack with other bonuses?
Yes! VIP bonuses stack with campaign bonuses and other promotions.

### How often is XP calculated?
XP is updated in real-time as you complete activities.
