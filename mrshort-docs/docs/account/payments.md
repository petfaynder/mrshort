# Payment Settings

Configure your payment methods for withdrawals.

## Accessing Payment Settings

1. Go to **Settings**
2. Click on **Payment Settings** tab

## Available Payment Methods

### PayPal

The most popular option for quick payouts.

**Setup:**
1. Enter your PayPal email address
2. Make sure it matches your verified PayPal account
3. Save changes

**Requirements:**
- Verified PayPal account
- Email must match PayPal registration

### Bitcoin (BTC)

Fast cryptocurrency payments.

**Setup:**
1. Enter your Bitcoin wallet address
2. Double-check the address (transactions are irreversible!)
3. Save changes

**Supported:**
- Native BTC addresses (starts with 1, 3, or bc1)

### USDT (TRC20)

Stable cryptocurrency option.

**Setup:**
1. Enter your USDT TRC20 wallet address
2. Verify it's a TRC20 address (not ERC20!)
3. Save changes

:::warning Network Matters!
Make sure you use a TRC20 (TRON) address. Sending to wrong network will result in lost funds!
:::

### Bank Transfer

Traditional bank payments.

**Setup:**
1. Enter bank name
2. Enter account holder name (must match your MRShort name)
3. Enter IBAN or account number
4. Enter SWIFT/BIC code
5. Save changes

**Processing:** 3-5 business days

### Payoneer

Global payment platform.

**Setup:**
1. Enter your Payoneer email
2. Must be a verified Payoneer account
3. Save changes

## Changing Payment Methods

You can change your payment method anytime:
1. Go to Payment Settings
2. Update the details
3. Save changes

:::info Verification
Some changes may require re-verification for security.
:::

## Security Tips

1. **Double-check addresses** - Crypto addresses can't be corrected after sending
2. **Use verified accounts** - Unverified PayPal/Payoneer may reject payments
3. **Keep details updated** - Old payment info can delay payouts
4. **Use unique addresses** - Don't share crypto addresses between platforms
