# Account Settings

Manage your MRShort account settings and preferences.

## Accessing Settings

Click **Settings** at the bottom of the sidebar.

## Profile Settings

### Personal Information
- **Username** - Your display name (can be changed)
- **Email** - Your login email (verification required to change)
- **Avatar** - Profile picture (auto-generated from name)

### Timezone
Set your timezone for accurate reporting and activity tracking.

## Security Settings

### Password
Change your password:
1. Enter current password
2. Enter new password
3. Confirm new password
4. Click **Update Password**

:::tip Strong Passwords
Use at least 12 characters with a mix of letters, numbers, and symbols.
:::

### Two-Factor Authentication (2FA)

Add an extra layer of security:
1. Go to **Settings → Security**
2. Click **Enable 2FA**
3. Scan QR code with authenticator app (Google Authenticator, Authy)
4. Enter verification code
5. Save backup codes securely

### Login History

View recent login activity:
- Date and time
- IP address
- Device/browser
- Location (approximate)

## Notification Settings

Control what notifications you receive:

| Notification Type | Email | In-App |
|-------------------|-------|--------|
| Payment updates | ✓ | ✓ |
| Achievement unlocks | ○ | ✓ |
| System announcements | ✓ | ✓ |
| Weekly reports | ○ | - |

## Theme Settings

- **Light Mode** - Bright theme
- **Dark Mode** - Dark theme (easier on eyes)
- **System** - Follows your device settings

## Language Settings

Select your preferred language for the dashboard interface.

## API Settings

Manage your API access:
- View API tokens
- Generate new tokens
- Revoke existing tokens
- View API usage statistics

See [API Documentation](/docs/api) for integration details.

## Delete Account

:::danger Permanent Action
Deleting your account is irreversible. All your data, links, and earnings will be permanently deleted.
:::

To delete your account:
1. Go to **Settings**
2. Scroll to bottom
3. Click **Delete Account**
4. Confirm with your password
5. Click **Delete Permanently**
