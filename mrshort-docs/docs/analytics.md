# Analytics

Track your performance and understand your audience with MRShort analytics.

## Dashboard Overview

Your main dashboard shows real-time statistics:

- **Today's Clicks** - Valid clicks received today
- **Today's Earnings** - Money earned today
- **Total Balance** - Available for withdrawal
- **Performance Chart** - Visual trend of your activity

## Reports Page

For detailed analytics, visit **Reports** in the sidebar.

### Available Reports

| Report | Description |
|--------|-------------|
| **Click Statistics** | Detailed breakdown by date |
| **Country Stats** | Traffic by country |
| **Device Stats** | Desktop vs mobile |
| **Top Links** | Your best performing links |
| **Referral Stats** | Earnings from referrals |

### Date Filters

You can filter reports by:
- Today
- Last 7 days
- Last 30 days
- Custom date range

## Link-Level Analytics

Click on any link in your **Links** page to see:

- Total clicks
- Unique clicks
- Earnings generated
- Traffic sources
- Geographic distribution

## Exporting Data

You can export your analytics data as CSV for further analysis.

:::tip Pro Tip
Check your analytics regularly to identify which content generates the most clicks!
:::
