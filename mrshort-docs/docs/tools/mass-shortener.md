# Mass Link Shortener

Shorten multiple URLs at once with the Mass Shortener tool.

## Accessing Mass Shortener

1. Go to **Tools** in the sidebar
2. Select **Mass Shortener**

## How to Use

### Step 1: Enter Your URLs

Enter one URL per line in the text area:

```
https://example.com/page1
https://example.com/page2
https://example.com/page3
```

### Step 2: Configure Options

Optionally set:
- **Custom aliases** (one per line, matching URL order)
- **Link expiration** (if available)

### Step 3: Process

Click **Shorten All** and wait for processing.

### Step 4: Download Results

After processing, you can:
- Copy all short links
- Download as CSV
- View individual link stats

## Limits

| Account Type | URLs per Batch | Daily Limit |
|-------------|----------------|-------------|
| Free | 50 | 200 |
| VIP Silver | 100 | 500 |
| VIP Gold | 200 | 1000 |
| VIP Diamond | 500 | Unlimited |

## Best Practices

1. **Verify URLs** before batch processing
2. **Use CSV format** for large batches
3. **Check for duplicates** to avoid redundant links
4. **Monitor performance** in Reports after creating

## Error Handling

If some URLs fail:
- Invalid URLs are skipped
- Error message shows which URLs failed
- Successfully shortened URLs are still saved

## Use Cases

- **Content creators**: Shorten all affiliate links at once
- **Marketers**: Prepare campaign links in bulk
- **Agencies**: Manage multiple client links efficiently
